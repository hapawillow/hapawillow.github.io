# The Notifier

The Notifier serves as a hub on their phone for personal alerts (alarms and local notifications) and external alerts (push notifications) and does it in a way that maintains user privacy without collecting email, phone number or any personal identifiable information (PII). Users can create alerts with alarms, note, links, that can repeat and sync with your calendars. An  a user opts-in to external alerts from an organization or businesses, which can broadcast a message to the phones of groups of users or send a personalized messages to an individual user

An business can send a message to a group of phones or an individual phone - The Notifier delivers the message without compromising the user's PII.
